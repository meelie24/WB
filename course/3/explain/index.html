Build the questionnaire

Turn your information needs into clear questions and a respondent journey that reaches the end.

Learning stage 1 of 4
1Explain2Show me3Do it with me4Try it myself

Words you’ll need

Questionnaire. The reusable form, which may start from a built-in sector questionnaire.

Define the form before adding its pages

Review the sector’s built-in questionnaire first; adapt it or create a custom one where needed. Name, Description and Sector must all be complete before Add Page activates. Group related questions into logical sections such as identification, customers and transactions.

Give every step a destination

Each step needs Title, Next Page and Type before questions/conditionals can be added. Select Start for the beginning, Page for intermediate sections and End for the final section. There can be several intermediate Page sections. Where a step leads nowhere, select None explicitly; an empty Next Page is missing information, not a selected ending.

Choose the answer format that fits

Single choice is one selection, including Yes/No; multiple choice is several selections. Dropdowns offer either selection mode. Single-line input is short text; long text is narrative; File is an attachment; Date, Currency and Number structure those values. Country single/multiple choice selects one/several countries. These are the guide’s twelve formats. Structured choices support aggregation; narrative needs manual review.

Make the wording usable

State the reporting period and unit. Make choices clear and non-overlapping, supply helpful descriptions and use required fields deliberately. Decide a category or None for every question before distribution; we will explain that decision in the next chapter. Preview is how you inspect what the respondent actually sees.

Build the follow-up before connecting it

The guide’s example asks whether the business served politically exposed persons (PEPs). Yes leads to an existing details page, such as PEP count/country; No skips it. Create the trigger question and target page before configuring the route. Check both answers and that both reach End.
