01

A completed setup handoff

The technical team confirms the application opens at the installed /backoffice address and ./data exists. You then create a colleague in User Management and the Real Estate sector in Configuration. The provisional survey.admin.thelos.io address in the guide is not an address this course connects to.

03

The same job using an import

For several businesses, use Import Excel with the guide’s CSV template. Its twelve headers include sector, identification, addresses, officers, website, email and phone. A row saying Property will not match a configured Real Estate sector. Correct the tag before import. The guide’s button/file wording and optional-website prose are inconsistent; use the explicit field list and approved template, and confirm actual validation in your installation.
